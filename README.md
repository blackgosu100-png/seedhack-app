# (이전 문서) 쿠팡 소싱 신호등 (데스크톱 프로그램) — v0.2

Electron 프로그램. 왼쪽은 **실제 Wing·쿠팡 화면**, 오른쪽은 **신호등 패널**(실제 상품 썸네일 카드 · 진행 콘솔 · 카테고리 판정 · 1688 허용 소싱가).
크롬 확장(wing-trend-helper) 설치 없이 동작한다.

## 실행
```
cd ~/projects/140_coupang-signal-app
npm start
```
1. 왼쪽 Wing 화면에서 로그인 (로그인은 쿠팡 페이지에서 직접 · 비밀번호는 프로그램이 저장·전송하지 않음, 세션만 PC에 유지)
2. 쿠팡 트렌드 → 인기상품 검색 → 카테고리 선택 → 오른쪽 패널이 자동으로 카드·판정을 그린다
   (이미 열린 화면이면 오른쪽 위 **🚦 판정** 버튼)
3. **🎯 상위 10개 정확한 판매량** → Wing 상품 매칭 조회가 4초 간격으로 진행, 카드에 28일 조회·판매·전환율이 채워짐
4. **⬇ 엑셀 저장** → 저장 창 → 상품 썸네일이 들어간 xlsx 생성 후 폴더가 열림
5. 위 **쿠팡 클린 세션** 탭 = 쿠키·로그인·기록 없는 메모리 전용 세션(시크릿 창과 같은 효과). **🕶 새 클린 세션**으로 언제든 새로 시작

### 전환율 비교 · 광고 가능성 (v0.2)
정확한 판매량을 받은 상품끼리 비교한다(패널 가운데 요약 줄 + 카드 아래 + 엑셀 열).
- **전환율 비교**: 중앙 전환율 대비 배수. 1.4배 이상 🔥(상품성 높음 — 같은 노출에서 더 많이 팔림), 0.75배 이하 ❄
- **광고 가능성**: 최대 ROAS = 판매가 × 실제 전환율 ÷ 최저 CPC 100원(가정) / 본전 ROAS = 100 ÷ 목표 마진율(광고 함 30% → 333%, 안 함 20% → 500%)
  - 🟢 광고 여유: 최대 ≥ 본전 × 1.5 · 🟡 빠듯: 최대 ≥ 본전 · 🔴 광고로 이익 불가: 최대 < 본전
  - 본전 CPC = 판매가 × 마진율 × 전환율(클릭 1번에 남는 돈), 최적 CPC ≈ 그 절반(클릭 수가 입찰가에 비례한다는 가정)
  - 주의: 최대 ROAS는 최저 CPC로 낙찰될 때의 상한이다. 경쟁 키워드의 실제 CPC가 본전 CPC보다 높으면 🟢여도 적자다 → 광고센터의 실제 CPC와 비교할 것

판정 기준(대표님 기준): 원가 계수 300 · 수수료 11.88% · 물류비 2,200원 · 광고 함 순이익률 30% / 안 함 20% · 틈새는 1위 리뷰 100 미만이 유리 · 큰 시장은 리뷰 500+로 수요 검증.
패널 위 버튼으로 틈새/큰 시장, 광고 함/안 함을 바꾼다.

## 구조
| 파일 | 역할 |
|---|---|
| `src/main/main.js` | 창·도구막대·사이트 화면(WebContentsView: Wing=persist:wing 세션, 쿠팡=메모리 전용 클린 세션)·IPC |
| `src/main/wing.js` | Wing이 받는 인기상품 응답을 CDP 네트워크 이벤트로 읽어 스냅샷 저장(페이지에 코드 주입 없음, 추가 요청 없음) |
| `src/main/exact.js` | 정확한 28일 조회·판매량(Wing 상품 매칭 검색). 4초 간격 · 10분 60건 · 하루 예산 · 한도 초과 24시간 정지 · 접근 제한 60분 정지 · 7일 캐시 |
| `src/main/excel.js` | 썸네일 포함 xlsx 생성(exceljs) |
| `src/main/store.js` | 로컬 저장(앱 데이터 폴더 `signal-data.json`) |
| `src/shared/strategy-core.js` | 판정 로직 — wing-trend-helper와 같은 파일(수정 시 양쪽 맞출 것) |
| `src/renderer/*` | 오른쪽 패널·도구막대 화면 |
| `test/fake-snapshot.json` | 자체 점검용 가짜 카테고리 |

자체 점검: `npm run selftest` (창을 띄우지 않고 가짜 데이터로 패널을 그려 캡처, Wing·쿠팡 접속 확인 후 종료. `SELFTEST_OUT=폴더`로 캡처 위치 지정)

## 원칙
- 차단 우회(브라우저 지문 위장, 캡차 우회)는 하지 않는다. 사람이 보는 화면과 그 화면이 스스로 받는 응답만 읽고, 막히면 멈춘다.
- 브라우저 표시 문자열에서 Electron·앱 이름만 빼고 크롬 엔진 표기는 그대로 둔다(사이트 호환용).
- 정확한 지표 조회는 각자의 Wing 로그인으로 요청이 나간다 → 하루 예산·속도 제한 유지. 수강생 배포 전 Wing 약관·법률 검토.

  - 로그인 유지 토큰은 safeStorage로 암호화합니다. 승인 상태는 6시간마다 다시 확인하고, 오프라인이면 3일 동안 유예합니다.
- **자동 업데이트**: 설치판(윈도우)이 GitHub 릴리스 `blackgosu100-png/coupang-signal-releases`에서 새 버전을 확인합니다.
  - 새 버전은 뒤에서 내려받습니다.
  - 설치는 "다시 시작해 업데이트" 버튼을 누르거나, 다음에 앱을 끌 때 됩니다.

### 새 버전 배포하는 법 (이 맥에서)
1. `package.json`의 `version`을 올립니다(예: 0.5.0 → 0.5.1). 버전이 같으면 업데이트되지 않습니다.
2. 아래 명령을 실행합니다.
   ```bash
   npm run release:win
   ```
3. 윈도우의 설치판이 켜질 때(또는 4시간마다) 자동으로 받아 갑니다.

주의: 설치 파일 안의 프로그램 코드는 풀어 볼 수 있습니다. 잠금은 앱 안에서 하는 것이고, 비밀 키는 앱에 넣지 않았습니다.

  - 1개당 광고비 = 클릭비용 ÷ (상품 전환율 × 광고 전환 비율)
  - 판정 기준(1개 마진 대비 1개당 광고비)

    | 판정 | 기준 |
    |---|---|
    | 🟢 | 2/3 이하 |
    | 🟡 | 이하 |
    | 🔴 | 초과 |

  - 기본값(대표님 광고 11개 캠페인 실측)

    | 항목 | 기본값 | 근거 |
    |---|---|---|
    | 클릭비용 | 145원 | 평균 146원, VAT 포함 |
    | 광고 전환 비율 | 40% | 광고 전환율 약 2.5% ÷ 상세페이지 전환율 6~7% |

  - 패널에서 둘 다 바꿀 수 있습니다.
  - 리스트업은 실제 1개 마진과 비교하고, "1개당 광고비" 칸을 보여 줍니다. "광고 안 함"이면 판정을 숨깁니다.
- **기타**
  - Wing이 데이터 대신 웹페이지를 돌려주면 원인(로그인 풀림·서버 오류·점검·보안 확인)을 구분해 표시합니다. 이런 응답이 3번 연속이면 멈춥니다.

## 📄 상세페이지 자동 생성 (2026-10-09 밤 구현, 실사이트 검증 전)

### 사용 순서(앱)
1. 📋 리스트업에서 🔍1688 → 1688 상품 페이지를 연다(또는 🇨🇳 1688 탭에서 상품 페이지를 직접 연다). **또는 📄 상세페이지 화면 맨 위 주소 칸에 1688 상품 주소(또는 상품번호)를 붙여넣고 ▶ 주소로 만들기** — 앱이 1688 탭에서 그 상품을 열어 읽은 뒤 자동으로 진행한다(로그인·보안 인증이 뜨면 1688 탭에서 넘기고 그 화면의 📄 버튼). 리스트업에서 고른 상품의 ▶ 딸깍도 같은 방식.
2. 상품 페이지 오른쪽 위 **📄 상세페이지 만들기** 버튼 → 앱이 📄 상세페이지 화면으로 넘어가며 "AI 작업 화면"이 9단계 진행을 보여 준다(상품 정보 읽기 → 이미지 내려받기 → 중국어 글자 찾기 → 글자 지우기 → 한글 번역 → 카피 작성 → 페이지 구성 → 렌더링 → 완료).
3. 완료 화면: 슬라이스 미리보기 · **📂 폴더 열기**(쿠팡 등록용 `out/01.jpg…`) · **🎨 피그마 묶음** · **🌐 HTML** · **↻ 다른 템플릿**(OCR·번역 재실행 없이 다시 렌더).
4. 쿠팡 Wing 상품 등록 → 상세 이미지에 `out/01.jpg…` 순서대로 올린다.

템플릿 3종: 화이트 클린 / 다크 프리미엄 / 컬러 팝. 결과 폴더: `앱 데이터/detail/<jobId>/` (raw 원본 · clean 지운 이미지 · out 결과 · source/ocr/plan/copy/result.json).
