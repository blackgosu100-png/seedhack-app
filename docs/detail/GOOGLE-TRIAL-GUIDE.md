# 내 구글 클라우드 연결하기 (수강생용 · 초안)

씨드핵 📄 상세페이지 · 🖼 썸네일의 AI는 **내 구글 클라우드 무료 체험**으로 돌아가요.

- 처음 가입하면 **90일 동안 $300(약 42만 원)** 크레딧을 줘요.
- 상세페이지 1개는 약 $1~3이 들어요. 크레딧 안에서 100개 넘게 만들 수 있어요.
- 카드를 등록하지만 본인 확인용이에요. **무료 체험이 끝나도 자동으로 결제되지 않아요.** 직접 "유료로 전환"을 눌러야만 결제돼요.

걸리는 시간: 처음 한 번 약 3분

---

## 연결하기 (버튼 하나)

1. 앱 📄 화면 → 설정 → **🔗 내 구글 클라우드** 칸의 **[🔗 구글로 연결]**을 눌러요.
2. 브라우저가 열리면 구글 계정을 고르고 **[허용]**을 눌러요.
   - "확인되지 않은 앱"이 보이면 **고급 → 씨드핵(으)로 이동**을 눌러요(구글 검증 신청 중).
3. 무료 체험이 처음이면 앱에 **"카드만 등록하면 끝나요"**가 떠요. 열린 구글 화면에서 나라 **대한민국** · 계정 유형 **개인** · 카드 입력 → **무료로 시작하기**.
   - 가입이 끝나면 앱이 알아서 다음으로 넘어가요.
4. 나머지(작업 공간 만들기 · 크레딧 연결 · AI 켜기 · 시험)는 앱이 자동으로 해요. **"연결 끝!"**이 뜨면 끝이에요.

> [스크린샷 자리: 연결 끝 화면]

중간에 멈추면 화면에 다음에 누를 것이 한 줄로 나와요. [다시 시도]를 누르면 멈춘 곳부터 이어서 해요.

---

# 고급: 키 파일로 연결 (버튼이 안 될 때만)

## 1단계. 무료 체험 가입 (5분)

1. 앱 📄 화면 → 설정 → **🔗 내 구글 클라우드** 칸에서 **[무료 체험 시작]**을 눌러요.
2. 구글 계정으로 로그인해요. 쓰던 지메일이면 돼요.
3. 나라 **대한민국**, 계정 유형 **개인**을 골라요.
4. 카드 정보를 넣어요. 본인 확인용이라 돈이 나가지 않아요.
5. "무료 체험 시작"을 누르면 끝이에요.

> [스크린샷 자리: 무료 체험 가입 화면]

- 화면 맨 위에 **"My First Project"** 같은 프로젝트 이름이 보여요.
- 그 옆의 **프로젝트 ID**(예: `my-first-project-123456`)를 메모해 둬요.

## 2단계. AI 기능 두 개 켜기 (2분)

앱 🔗 칸에서 아래 두 버튼을 차례로 누르고, 열린 화면에서 파란 **[사용]** 버튼을 눌러요.

1. **[Vertex AI 켜기]** — 글 AI·이미지 AI
2. **[Cloud Vision 켜기]** — 중국어 글자 읽기

> [스크린샷 자리: API "사용" 버튼]

## 3단계. 키 파일 만들기 (5분)

앱이 내 프로젝트를 쓰려면 **키 파일** 하나가 필요해요.

1. 구글 클라우드 화면 왼쪽 메뉴에서 **IAM 및 관리자 → 서비스 계정**으로 가요.
2. 위쪽 **[+ 서비스 계정 만들기]**를 눌러요.
   - 이름: `seedhack`
   - [만들고 계속하기]를 눌러요.
3. 역할 칸에서 **"Vertex AI 사용자"**를 골라요.
   - [계속] → [완료]를 눌러요.
4. 목록에 생긴 `seedhack@…` 를 눌러요.
5. 위쪽 **[키]** 탭 → **[키 추가] → [새 키 만들기] → JSON → [만들기]**를 눌러요.
6. 파일 하나가 내려받아져요(예: `my-first-project-123456-abcd.json`).

> [스크린샷 자리: 서비스 계정 키 만들기]

- 이 파일은 **비밀번호와 같아요.** 다른 사람에게 보내거나 카톡·메일에 올리지 마세요.

## 4단계. 앱에 연결 (1분)

1. 내려받은 키 파일을 앱 🔗 칸 위로 **끌어다 놓아요.** 또는 [📄 키 파일]을 눌러 골라요.
2. 앱이 바로 세 가지를 확인해요.
   - ✔ 글 AI(Gemini) 연결됨
   - ✔ 이미지 AI(나노바나나) 연결됨
   - ✔ 글자 읽기(Cloud Vision) 연결됨
3. 셋 다 ✔ 이면 끝이에요. 키 파일은 앱 안에 복사됐으니, 내려받은 파일은 지워도 돼요.

> [스크린샷 자리: 연결 확인 ✔ 세 줄]

### ✕ 가 뜨면

| 안내 | 할 일 |
|---|---|
| "Vertex AI API 가 꺼져 있어요" | 2단계 ① [사용] 누르기 |
| "Cloud Vision API 가 꺼져 있어요" | 2단계 ② [사용] 누르기 |
| "구글 결제 계정(무료 체험)이 연결되지 않았어요" | 1단계 무료 체험 가입 마치기 |
| "구글 연결 권한이 없어요" | 3단계 ③ 역할을 "Vertex AI 사용자"로 다시 주기 |
| "구글 AI 가 잠시 바빠요" | 1~2분 뒤 [확인] 다시 누르기. 처음 며칠은 분당 한도가 낮아요 |

## 남은 크레딧 보기

- 앱 🔗 칸의 **[남은 크레딧 보기]**를 누르면 구글 결제 화면이 열려요.
- 앱에는 "무료 체험 약 ○일 남음"이 보여요. 앱에 연결한 날부터 90일로 셈한 값이라, 정확한 날짜는 구글 화면이 기준이에요.
- 90일이 지나거나 $300을 다 쓰면 구글 AI가 멈춰요.
- 그때는 🔗 칸에서 [끊기]를 누르면 "씨드핵 서버"로 쓸 수 있어요. 서버는 하루 쓸 수 있는 양이 정해져 있어요.

## 다른 방법: API 키로 연결

키 파일이 안 될 때만 써요. 이 방법도 서비스 계정이 필요해요.

1. **API 및 서비스 → 사용자 인증 정보 → [+ 사용자 인증 정보 만들기] → API 키**를 눌러요.
2. **"서비스 계정을 통해 API 호출 인증"**에 체크하고 `seedhack@…` 를 골라요.
3. **API 제한**에서 Vertex AI API, Cloud Vision API 두 개만 골라요.
4. 만들어진 키(`AIza…`)와 프로젝트 ID를 앱 🔗 칸에 붙여 넣고 **[연결]**을 눌러요.

### 만든 사람 메모 (수강생에게는 안 보여 줌)

- $300 크레딧은 Vertex AI·Cloud Vision 에 쓰여요. AI Studio(Gemini API) 키에는 안 쓰여요 → AI Studio 키는 받지 않아요.
  - 근거: [Gemini API 결제 문서](https://ai.google.dev/gemini-api/docs/billing), [Google Cloud 무료 체험 문서](https://docs.cloud.google.com/free/docs/free-cloud-features)
- Vertex 는 일반 API 키를 받지 않고 서비스 계정에 묶인 키만 받아요.
  - 근거: [API 키 관리 문서](https://docs.cloud.google.com/docs/authentication/api-keys)
- 무료 체험으로 Gemini 이미지 모델을 쓰는 공식 안내가 있어요.
  - 근거: [Getting started with Gemini 3 Pro Image (free trial)](https://cloud.google.com/blog/topics/developers-practitioners/getting-started-with-gemini-3-unlocking-the-cloud-with-the-free-trial)
- "구글로 연결" 버튼(OAuth)은 지금 안 써요.
  - cloud-platform 범위는 검증 전에는 앱 평생 100명까지만 받아요.
  - 테스트 모드면 7일마다 다시 로그인해야 해요.
  - 검증에는 개인정보처리방침·도메인·시연 영상이 필요하고 몇 주가 걸려요.
  - 근거: [Manage App Audience](https://support.google.com/cloud/answer/15549945)
- 새 프로젝트는 gemini-2.5-pro 가 404 예요(2026-10-23 실측). 글 AI 는 gemini-3.1-pro-preview·gemini-2.5-flash 를 써요.
