# 레퍼런스 분석 — 브랜든 "여행 압축 파우치 라이트 세트" 상세 (대표님 지정, 2026-10-11)
원본: 상세 이미지 27장(가로 1000px, 순서 order.txt) + 한눈에 보기 시트 2장. 새 테마 `branden`(브랜든 스타일)의 기준.

## 왜 고급스러워 보이나 (핵심 규칙)
1. **흰 바탕 하나.** 브랜드 색·강조 색 없음. 제목 검정(#111), 본문 진회색. 어두운 띠·그림자·둥근 카드·키커 알약 없음.
2. **글 → 사진 → 글 → 사진.** 글은 사진 위에 절대 얹지 않는다. 사진은 꽉 차게(가로 전체) 또는 흰 바탕 위 제품 단독.
3. **짧은 제목 + 2줄 설명.** 제목 1~3단어("압축력", "초경량", 약 40px@1000 굵게), 설명 2줄(약 30px@1000, 줄 간격 1.6), 필요하면 작은 메모 한 줄("* S 110g | M 190g").
4. **왼쪽 정렬 + 큰 왼쪽 여백(가로의 약 8.5%).** 블록 사이 위아래 여백 120~160px — 비어 보일 만큼 넓다.
5. **첫 화면**: 왼쪽 정렬 3줄 제목(마지막 줄 = 제품명) + 짧은 회색 문단 → 글 없는 생활 장면 사진 여러 장.
6. **디테일**: 2×2 사진 격자, 각 사진 아래 작은 굵은 라벨 + 회색 2줄.
7. **사이즈**: 흰 바탕 누끼 + 가는 치수선과 숫자.
8. **정보 판**: 연회색(#f2f2f2) 판 안에 왼쪽 키 / 오른쪽 값 표(가는 선), 그 아래 번호 목록(세탁·관리, 사용 시 주의, 구매 전 참고).
9. 강조는 굵기만. 밑줄 띠·색 글자·기울기 없음.

## 섹션 → 스타일 대응 (card 엔진 + themes/branden.css)
| 섹션 | branden 에서 |
|---|---|
| hero | 글(제목 줄 = 보조문·제품군·제품명, 44px 왼쪽 정렬) → 아이콘 띠 글자를 회색 한 줄(`a \| b \| c`)로 → 글 없는 꽉 찬 사진. 히어로 전체 ≤ 1100 |
| problem | 어두운 띠 없이 왼쪽 정렬 질문(제목) + 회색 한 줄 |
| before_after | 제목 → 설명 → 꽉 찬 사진. BEFORE/AFTER 는 작은 흰 사각 라벨(검정 글자) |
| checkpoint | 글 → 사진, 지시선은 1px 검정 선 + 작은 점 + 작은 검정 라벨(그림자·둥근 모서리 없음) |
| feature / feature2 / options | 카드 없음: 제목 + 2줄 → 꽉 찬 사진 |
| detail | 글 → 사진. 사진이 항목보다 적으면 사진은 꽉 차게, 라벨 + 2줄은 아래 2열 / 모두 있으면 2×2 격자 + 라벨. 확대 원은 가는 회색 테두리·검정 선 |
| versatility | 글 → 사진(1장이면 꽉 차게 + 라벨 한 줄 `주방 \| 데스크 …`, 여러 장이면 2×2 + 왼쪽 라벨) |
| spec · notice · faq · size · package | 이어지는 연회색 판. 표는 왼쪽 키 / 오른쪽 값 + 가는 선, 주의는 `1.` 번호 목록, FAQ 는 `Q.` `A.` 글자만 |
| 신뢰 블록(trust_badges·sold_out·rank·rnd·cert·official·review) | 흰 바탕 글 위주. 원형 배지·어두운 띠 대신 큰 숫자 + 회색 설명, 아이콘 띠는 가는 세로선 |
| 강조(emph·title_lines) | 굵기만(색·밑줄·점·알약 끔) |

## 그대로 못 따라 한 것
- 레퍼런스는 생활 장면 사진이 많아 사진만 연달아 쌓는 구간이 있다. 우리 엔진은 섹션마다 사진 1장이 기본이라 "사진만 여러 장" 구간은 없다.
- 사이즈 치수선 도면은 엔진에 그 섹션이 있을 때만(size). 커피 수납랙 작업에는 없다.
- 본문 글자는 앱 가독성 기준(본문 24px·캡션 22px 이상) 때문에 레퍼런스의 작은 메모·주의 글씨(약 16px@780)보다 크다.
