## 왜 깔끔한가 (핵심 규칙)
1. **브랜드 색 하나**(로열 블루)만 강조에 씀. 다른 강조 색 없음.
2. **강조는 "줄 단위"**: 2줄 제목에서 둘째 줄 전체를 브랜드 색으로("3D로 퍼지는 / **360° 입체 세척**"). 단어 중간 점·밑줄·기울기 같은 장식 없음.
3. **섹션 머리 = 키커 알약**(POINT 1 / Difference 1 / UPGRADE 1, 검정 또는 파랑 그라데이션) → 굵은 2줄 제목(가운데) → 회색 보조문 2줄. 모든 섹션이 같은 문법.
4. **명도 리듬**: 흰 섹션 ↔ 진남색/검정 섹션 교대. 문제 제기는 어두운 배경 + 말풍선 꼬리("이걸 한 번에 해결할 순 없을까?") → 다음 섹션에서 해결(제품 등장).
5. **구성 블록**: 아이콘 띠(브랜드 색 배경 + 흰 라인 아이콘 + 세로 구분선), 비교 카드 2장(구형 회색 vs 신형 파랑 테두리 + NEW 배지), BEFORE/AFTER 2분할 + 화살표, 용도 2×2 격자(사진 + OK 원형 배지 + 브랜드 색 캡션 띠: 굵은 제목 + 한 줄 설명), 후기 카드(사진 + #해시태그 제목 + 굵은 핵심 구절), FAQ 흰 카드, 주의사항 검정 섹션(× 목록), 제품 사이즈 도면.
6. 글자: 굵은 고딕 제목(800~900), 본문 회색 400, 가운데 정렬, 여백 넉넉.

## 우리가 따라 하면 안 되는 것
"7차 완판", "1위", "연구 개발 비용 2억", "KC 인증 번호", "100% 실사용 후기", 공식 판매처 마크 — 근거 없는 수치·인증·순위. 실제 데이터가 있을 때만(셀러 입력).
