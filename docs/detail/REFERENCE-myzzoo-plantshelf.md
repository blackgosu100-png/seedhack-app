## 디자이너가 실제로 한 일 (중국 원본 → 완성본)
1. **중국 상세 이미지는 레이아웃·글자를 하나도 쓰지 않았다.** 업체 사진은 "제품이 어떻게 생겼는지" 참고용.
2. **AI 이미지 생성으로 장면을 새로 찍었다(핵심).** 제품을 한국 아파트 베란다·거실·창가에 놓은 장면, 물방울 맺힌 클로즈업, 호스로 물 주는 손, 다리를 펴는 손, 접어서 벽에 기대 둔 모습, 분재·다육이 가득 올린 모습 — 전부 Gemini(나노바나나)/ChatGPT 생성. 같은 장면을 여러 번 생성해 고른 흔적(60장 → 10여 장 사용).
3. **진짜 증거를 섞었다.** 고객 후기 사진 16장 격자 + 별점 4.8 / "리뷰 통합 300+" + 후기 6개 카드(핵심 구절 노란 형광 강조). 직접 촬영 사진(접힌 제품).
4. **글은 아주 적다.** 섹션마다 "POINT. 0N + 기능명" 알약 라벨 → 큰 사진 → `*` + 한 줄 제목 → 두 줄 설명. 설명은 2줄을 넘지 않는다.
5. **에디토리얼 타이포.** 영문 세리프 대형 타이틀(BLACK PLANT SHELF, CHECK POINT, FOR YOU.), 필기체 소제목(Midcentury), 한글은 가는 산세리프. 키워드 표(FLOW/EASY/FOLDING/STABLE/MINIMAL + 영문 작은 설명 + 한글).
6. **사진은 꽉 차게(full-bleed).** 카드·테두리·그림자 없음, 회색 톤 배경 하나로 통일, 사진끼리 2분할 배치.
7. **구성:** 히어로(영문 타이틀+감성 한 줄) → 옵션·사이즈 표 + 제품 누끼 → 키워드 5개 → 리뷰(사회적 증거, 앞쪽!) → CHECK POINT(누끼에 지시선 5개) → FOR YOU(이런 분께 4줄) → POINT 01~05(기능별 장면 사진) → 갤러리(실사용 후기 사진) → GIF(접는 동작).

## 우리 v1/v2와의 차이 → 고칠 것
| 레퍼런스 | 우리 | v3 할 일 |
|---|---|---|
| AI로 한국 생활 장면을 새로 생성 | 중국 사진을 자르고 지워서 재사용 | **이미지 생성 단계**(Gemini 이미지 편집: 원본 제품 사진 → 장면 프롬프트, 기능별 3~6장) |
| 사진 꽉 참, 톤 통일 | 둥근 카드·그림자·연한 박스 | **editorial 템플릿**(full-bleed, 무카드, 회색 단일 톤) |
| 글 2줄, 알약 라벨 + `*` 제목 | 캡션 박스에 설명 문장 | 카피 길이 상한 강화(제목 ≤14자, 설명 2줄 ≤ 40자) |
| 영문 세리프 타이틀·키워드 표 | 한글 산세리프만 | 영문 타이틀/키워드(FLOW…) 자동 생성 + 세리프 글꼴 |
| 누끼 + 지시선 CHECK POINT | 없음 | 누끼에 지시선 4~5개(위치는 vision이 좌표 지정) |
| 리뷰 격자·별점(진짜) | 없음(신규 상품) | 리뷰 입력 칸(셀러가 자기 리뷰 사진·문구를 넣으면 섹션 생성, 없으면 생략 — 가짜 리뷰 금지) |
| 이런 분께(FOR YOU) | 공감 3줄(이모지) | FOR YOU 4줄로 대체 |
| GIF(동작) | 없음 | 범위 밖(추후) |

## 결론
품질 차이의 70%는 **사진**이다. 중국 사진을 아무리 잘 다듬어도 레퍼런스 수준이 나오지 않는다. 디자이너처럼 **AI 이미지 생성으로 장면을 새로 만드는 단계**가 필요하고, 이것은 이미지 생성 API(Gemini 이미지 모델 = 나노바나나)가 있어야 한다.
