## 재작업 1 — 상품명 자리에 판매자 회사명 (2026-10-09, 실제 1688 두 건)
증상: 실제 작업 `20261009-080956-948424797701`, `20261009-132404-841080065939` 의 `title_zh` 가 회사명(温州莱龙卫浴有限公司 / 东莞中正家具有限公司). 원인: 기존 `readTitle()` 이 문서의 **첫 h1** 을 쓰는데 1688 새 화면은 판매자 회사명 h1 이 상품명보다 앞에 있음.

고친 것
- `cn.cjs`(덧붙인 부분): `readTitleCandidates()/readDetailTitle()` — 후보 순서 ① 페이지 스크립트 JSON `"subject"`·`"offerTitle"` ② 상점 영역(조상 class/id 에 shop/company/seller/store/supplier/winport/enterprise/factory) **밖**의 `h1`·제목 class(title-text/offer-title/detail-title/main-title/item-title) ③ `og:title` ④ `document.title`(꼬리 " - 阿里巴巴"·"-淘宝网"·"| 1688" 등 제거) ⑤ 스크립트 `"title"` ⑥ 그 밖의 `[class*=title]`. 회사명으로 보이는 후보는 건너뜀. raw 에 `titleCandidates: [{t, from}]`(최대 12) 를 함께 보냄.
- 회사명 판별(`COMPANY_RE`): `有限责任公司|股份有限公司|有限公司|公司|工厂|厂|商行|贸易|实业|商贸|经营部|旗舰店|专营店|专卖店` + 1688 한국어판 `유한회사|유한공사|주식회사|회사|공장|상사|무역|상회` 로 **끝나면** 회사명("工厂直销 收纳盒"·"公司年会礼品 保温杯" 은 상품명으로 통과).
