## 규약(CONTRACTS)과 다르게 한 점
- `initDetail` 인자: `win` 대신 `getWin`, 추가로 `getCnView`(fromPage 보낸이 확인), `showDetail`(main 의 `active="detail"; layout()` — `send("nav")` 만으로는 main 쪽 사이트 화면이 안 숨겨짐).

- 추가 파일 `clean.json`(지우기 결과, 재렌더 때 재사용)·`translate.json`(번역표, 재렌더 때 재사용). `ocr.json` 에는 번역 후 상자마다 `text_ko` 를 더한다(바뀐 게 있을 때만 다시 씀).

## 알려진 한계
- 1688 실사이트에서 📄 버튼(A1 cn.cjs) → `detail:fromPage` 흐름은 e2e 에서 가짜 sender 로만 검증(실사이트 접속 금지 원칙). 앱을 띄워 실제로 눌러 보는 검증은 아침에.
- 앱이 실행 중에 작업은 **한 번에 하나**(진행 중 재실행은 한국어 사유로 거절).
- 결과 미리보기는 `file://` 이미지라 CSP `img-src` 에 `file:` 을 넣었다(패널은 로컬 파일 화면이라 위험 낮음).
- 자체 렌더(대체 동작)는 사진 위 글자 overlay 띠를 그리지 않는다(A4 템플릿이 담당). 사진 속 로고(厂家直销 등 사진 위 글자) 는 A2 가 `kept` 로 남기면 결과에 그대로 보일 수 있음(F-4 ➖ 후보).
- 번역은 기존 translate.js(DeepL 키 없으면 구글 무료) — 네트워크 없으면 원문 유지.
- 발표 모드 ZOOM(1.25) 은 패널 전체 확대 + detail.css 글자 확대가 겹친다 — 작은 창(1100px 폭)에서는 격자/터미널이 빡빡할 수 있음.

## "로고 있음" 토글 — 자동 검수가 놓친 작은 로고를 사람이 표시
- 확인 화면 사진 카드마다 "로고?/로고 있음"(vision `any_logo_visible`·`has_logo` 값으로 시작) → `info.logos[id]`. 결과 화면 섹션 목록 사진마다 같은 토글 → `detail:logo:set`: 장면이면 scene.json 항목에 `human:"logo"`·`any_logo_visible:true`, 원본 사진이면 `info.logos`.
