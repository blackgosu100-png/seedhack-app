# 씨드핵 가독성 매뉴얼

대표님이 반복해서 잡아 준 기준을 모은 것. 화면을 만들거나 대표님께 보고하기 **전에** 이 순서로 확인한다.
새로 지적받은 디테일은 맨 아래 "추가 기록"에 날짜와 함께 한 줄로 붙인다.

## 1. 대표님께 보고하는 글

1. **첫 줄 = 결론.** 무엇이 됐는지, 대표님이 할 일이 있는지. 배경 설명으로 시작하지 않는다.
2. **한 줄에 한 가지.** 줄표(—)·괄호로 문장을 이어 붙이지 않는다. 길어지면 줄을 나눈다.
3. **목록은 3~5개.** 넘으면 묶거나 덜 중요한 것을 뺀다.
4. **쉬운 말 먼저, 기술 말은 맨 아래.** 파일 경로·함수 이름·주소는 "바뀐 파일" 같은 맨 아래 칸에만.
5. **숫자는 예시와 함께.** "급증 탐지" 대신 "8/24~9/21 리뷰 104개(86%)".
6. **확인 안 된 것은 한 칸에 따로.** 본문 곳곳에 "추정·미검증"을 흩뿌리지 않는다.
7. **표는 비교할 때만.** 설명을 표에 넣지 않는다.
8. **대표님께 물을 것은 맨 끝에 하나만.**

## 2. 앱 화면

1. **결론을 크게, 먼저.** 맨 위에 한 줄 요약 + 큰 숫자 2~3개. 표·세부 수치는 그 아래 또는 "자세히"로 접는다. (기본은 단순, 원하는 사람만 펼침)
2. **본문은 밝은 화면.** 흰 바탕·회색 글자 + 초록 하나. 어두운 해커 톤은 **진행 중 연출에만**.
3. **글자 크기.** 본문 13~14px 이상, 핵심 숫자 22px 이상·굵게. 회색 보조 글자는 한 줄 이내.
4. **문장 대신 라벨 + 숫자.** "이 기간 5점 100% · 이후 44%" → 칩 `5점 100%`. 설명 문장은 20자 안팎.
5. **색은 뜻이 있을 때만.** 빨강 = 주의, 주황 = 한계·확인 필요, 초록 = 좋음. 장식용 색 금지.
6. **판정은 내지 않는다.** GO/DROP 대신 "참고 지표"로. (2026-10-09 대표님 결정)
7. **한 화면 상자 5개 이하.** 넘으면 접는다.
8. **결과 화면도 연출과 같은 급.** 진행 연출만 화려하고 결과가 작은 상자면 안 된다. 바뀐 결과는 눈에 보이게.
9. **진행 중엔 계속 움직임.** 실제 진행 상태만 보여 준다(가짜 숫자 금지). 반복·왕복 연출 금지.
10. **우리 말로.** 핵심 표현은 "시그널". 다른 서비스 표현(꿀통 등)·농사 말장난 금지.
11. **아이콘 버튼엔 반드시 마우스 오버 설명.** 아이콘만 있는 버튼은 올리면 0.3초 안에 "무엇을 하는지" 한 줄 말풍선(예: "📂 결과 폴더 열기"). 기본 title 속성만으로는 늦게 떠서 안 됨. 자주 쓰는 1~2개는 아이콘 옆에 짧은 글자도.
12. **필요 없는 안내 문구는 없앤다.** 빈 상태 설명·사용법 문장은 처음 한 번만, 결과를 볼 때는 숨긴다.

## 3. 보내기 전 체크

- [ ] 첫 줄만 읽어도 무슨 일인지 아는가
- [ ] 3초 안에 가장 큰 숫자가 눈에 들어오는가
- [ ] 줄표·괄호로 이어 붙인 긴 문장이 없는가
- [ ] 기술 용어가 본문에 섞이지 않았는가
- [ ] 접어도 되는 세부가 펼쳐져 있지 않은가

## 추가 기록

- 2026-10-10 키워드 추천: 메뉴를 열면 결과 없이 버튼·설명만 있는 시작 화면 → 버튼을 누르면 해커 화면 → 결과가 위에서부터 차례로. 결과를 미리 깔아 두지 않는다.
- 2026-10-10 라이브커머스 시연용 키워드 추천 첫 화면: 초보(부업) 대상 — 조건 이름 대신 결과를 말하는 카드("아직 빈자리가 있는 상품") + 왜 좋은지 한 줄 + 실제 예시 키워드·개수, 맨 위 큰 버튼 하나. 셀러 용어(로켓그로스 등)는 작은 글씨로만.
- 2026-10-10 키워드 추천: 조회한 결과는 다른 탭에 다녀와도 그대로 둔다(처음으로 돌아가면 아쉽다). 시작 화면은 아직 조회 전일 때만, 다시 조회는 결과 위 버튼으로.
- 2026-10-10 상세페이지 결과 화면: 위 메뉴가 너무 높음 → 맨 위 한 줄만 고정, 나머지 함께 스크롤. 왼쪽 위 안내 문구 불필요, 오른쪽 위 아이콘이 무엇인지 모름 → 오버 설명 필수(2-11·2-12).
- 2026-10-11 상세페이지 섹션 편집: 목록이 좁음 → 넓히고, 썸네일은 글만 있는 섹션도 완성 화면을 잘라 이미지로. 오른쪽 편집 칸이 화면 밖으로 잘림 → 칸을 열면 미리보기가 줄어들고 글 칸은 내용 길이만큼 늘어나 전부 보이게.
