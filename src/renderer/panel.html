• 고정 IP 1개: 한 줄만 넣으면 모든 쿠팡 탭이 해당 IP로 고정 연결됩니다.
• 여러 개 로테이션: 여러 줄을 넣으면 세션마다 순환하고, “사용권한이 제한된 페이지”가 뜨면 차단된 IP를 제외하고 다음 프록시로 자동 전환합니다.
• ID/PW 인증: HTTP/HTTPS 프록시는 IP:PORT:ID:PW 또는 http://ID:PW@IP:PORT 자동 인증 지원 (SOCKS5는 IP 화이트리스트 권장).
